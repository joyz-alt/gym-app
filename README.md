# GymFlow

GymFlow est une application de gestion de salle de sport développée dans le but de réviser les notions vues en Licence Informatique.

Le projet est volontairement développé progressivement afin d'apprendre à concevoir une application complète en partant d'une feuille blanche.

---

## Objectifs

- Concevoir une architecture logicielle propre
- Appliquer les principes de la programmation orientée objet
- Manipuler différentes structures de données
- Concevoir une base de données relationnelle
- Développer une interface Web dynamique
- Communiquer avec une base PostgreSQL
- Découvrir les communications client/serveur
- Produire quelques statistiques sur les données
